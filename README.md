# FrameZip

أداة عربية لاستخراج إطارات الفيديو داخل المتصفح مع ترقيم الملفات وتنزيلها كملف ZIP.

## النشر على GitHub Pages

- فيديو الخلفية المستخدم داخل المستودع: `public/media/background-web.mp4`
- الدقة: 1920×1080
- معدل الإطارات: 30fps
- الحجم: حوالي 23MB
- فيديو 4K محفوظ خارج المستودع بسبب حد GitHub البالغ 100MB للملف الواحد.

شغّل الموقع محليًا عبر:

```bash
node server.js
```
